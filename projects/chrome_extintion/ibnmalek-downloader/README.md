# جامع دروس ابن مالك — نسخة أولية 0.1.0

## التثبيت
1. فك ضغط `ibnmalek-downloader.zip` في مجلد ثابت.
2. افتح `chrome://extensions` في Chrome أو `edge://extensions` في Edge.
3. فعّل Developer mode / وضع المطوّر.
4. اختر Load unpacked / تحميل إضافة غير مضغوطة وحدد مجلد `ibnmalek-downloader`.
5. سجّل الدخول للموقع بالطريقة المعتادة، وافتح صفحة المقرر.

## تجربة النسخة الأولى
- **الإضافة ON**، وعلى صفحة المقرر: اضغط أيقونة الإضافة ثم «جمع / تحديث بيانات الصفحة».
- **الإضافة ON**، وعلى صفحة درس بعينها: اضغط الزر نفسه لجمع روابط المرفقات الظاهرة في الصفحة.
- افتح صفحات الدروس المطلوبة واحدة تلو الأخرى واجمع بياناتها؛ هذه النسخة لا تتنقل تلقائيًا بين صفحات الدروس بعد.
- اضغط «تحميل المرفقات المكتشفة» لتنزيل الروابط المباشرة المكتشفة إلى مجلدات تحت مجلد التنزيلات، باسم `[رقم الدرس] - [اسم الدرس]` عندما تتوفر بيانات الرقم والعنوان.
- زر CSV يصدر فهرس الدروس المحفوظ محليًا.

## ما يعمل حاليًا
- واجهة عربية بها حالة المهمة، عدد الدروس والمرفقات، سجل عمليات.
- تخزين محلي عبر `chrome.storage.local`.
- مقارنة بصمة البيانات لتحديد الجديد والمتغير والذي لم يتغير.
- تنزيل المرفقات المباشرة المكتشفة بالتوازي، بعدد افتراضي 3 يمكن تغييره.
- أسماء مجلدات مستقلة لكل درس عند التنزيل.
- تصدير فهرس الدروس CSV.

## ما لم يكتمل بعد (لا تعتبره ميزة جاهزة)
- الزحف التلقائي إلى كل صفحات الدروس وجمعها على دفعات، مع إعادة فحص ذكية لرؤوس HTTP مثل ETag وLast-Modified حيث يدعمها الموقع.
- إنشاء PDF عربي من التمارين آليًا؛ استخراج HTML موجود كبداية لكنه لا يصدر PDF بعد.
- تنزيل YouTube واختيار جودته. روابط `watch?v=` أو صور المصغرات ليست روابط ملف فيديو. هذه الإضافة لا تتجاوز حماية YouTube ولا تستخرج روابط بث مخفية؛ خيار الجودة واجهة إعداد أولية لمرحلة دعم روابط الفيديو المباشرة المسموح بتنزيلها.
- استئناف تنزيلات متعثرة بمطابقة كل مهمة مع سجل Chrome Download ID بشكل كامل.
- دعم مؤكد لكل صفحات الموقع الفرعية. الـ host permissions الحالية مبنية على أسماء النطاقات الظاهرة في ملف المصدر وقد تحتاج تعديلًا إذا كان عنوان الموقع الفعلي مختلفًا.

## الخصوصية
البيانات التي تجمعها النسخة الأولية محفوظة في تخزين الإضافة المحلي. لا توجد اتصالات بخدمات خارجية أضافتها الإضافة.
- زر «جمع تفاصيل كل الدروس المحفوظة» يفتح صفحات الدروس في تبويبات خلفية على دفعات محدودة، ويجمع المرفقات المكتشفة ويحفظ البصمات. يفضّل البدء على صفحة المقرر بعد تسجيل الدخول.
- زر «تجهيز التمارين للطباعة PDF» يفتح صفحة طباعة موحّدة للتمارين التي نجح اكتشافها؛ اضغط زر الطباعة أو Ctrl+P واختر «حفظ بتنسيق PDF». لا يزال التقاط التمارين يعتمد على بنية الصفحة الظاهرة، لذلك يلزم التحقق من أول PDF قبل الاعتماد عليه.
