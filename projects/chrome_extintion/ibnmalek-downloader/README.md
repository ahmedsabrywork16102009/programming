# Ibn Malek Lesson Downloader

## Installation

1. Extract the `ibnmalek-downloader.zip` archive into a permanent folder.
2. Open `chrome://extensions` in Chrome or `edge://extensions` in Edge.
3. Enable Developer mode.
4. Choose `Load unpacked` and select the `ibnmalek-downloader` folder.
5. Sign in to the website and open a course page.

## Features

- Collect course and lesson data.
- Store data locally with `chrome.storage.local`.
- Compare data fingerprints to detect new, changed, and unchanged records.
- Download discovered attachments in parallel.
- Export the lesson index as CSV.
- Prepare discovered exercises for printing or PDF export.

## Privacy

Collected data is stored locally in the extension. The extension does not send data to external services.
