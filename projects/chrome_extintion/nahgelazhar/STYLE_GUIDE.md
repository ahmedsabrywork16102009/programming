# 📜 دليل معايير وتوثيق التطوير (Extension & Web Style Guide)

هذا الملف يمثل المرجع المعياري للمشروع للتأكد من اتباع أفضل الممارسات البرمجية وتحديث التوثيق باستمرار بعد كل مرحلة تطوير.

---

## 1. ⚙️ معايير تطوير إضافات المتصفح (Chrome Extension Standards)
* **الإصدار المعياري:** استخدام `Manifest V3` حصرياً لجميع الإضافات.
* **فصل المسؤوليات:**
  * `manifest.json`: مخصص لإعدادات الأذونات والسكربتات المعتمدة فقط.
  * `content.js`: يحتوي على المنطق التنفيذي والتفاعل مع عناصر الـ DOM بشكل مستمر ونظيف.
* **التعامل مع تطبيقات الـ Single Page Applications (React):**
  * استخدام `MutationObserver` لمراقبة تحميل الـ React Components بالكامل قبل تنفيذ عمليات التكتم والسكرول.
  * استهداف نصوص المحاضرات (مثل: "المحاضرة الأولي-نحو") لتحديد المكان بدقة فتحها وعمل Scroll Into View إليها مباشرة.

---
